# Test with Ankita — ऑनलाइन परीक्षा प्लेटफार्म (Rebuild)

यह एक पूर्ण, सुरक्षित और मोबाइल-फ्रेंडली ऑनलाइन परीक्षा प्रणाली है जिसमें गणित, रीजनिंग और हिंदी विषयों के लिए अलग-अलग सेक्शन, HTML टेस्ट इम्पोर्टेबिलिटी, मैन्युअल क्वेश्चन एडिटर, और लाइव लीडरबोर्ड उपलब्ध हैं।

---

## 📦 ज़िप डाउनलोड और एक्सट्रैक्ट करना
1. दिए गए लिंक से **test-with-ankita-complete.zip** डाउनलोड करें।
2. अपने फोन में ZArchiver या किसी अन्य फ़ाइल मैनेजर ऐप का उपयोग करके ज़िप को एक्सट्रैक्ट करें।

---

## 🚀 GitHub पर अपलोड और Render पर डिप्लॉय कैसे करें
1. GitHub पर एक नई Public Repository बनाएं और सभी फ़ाइलें अपलोड करें।
2. Render.com पर जाकर Web Service कनेक्ट करें।
3. Build Command: `npm install`, Start Command: `npm start` सेट करें।
4. Environment Variables जोड़ें: `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `SESSION_SECRET`।
