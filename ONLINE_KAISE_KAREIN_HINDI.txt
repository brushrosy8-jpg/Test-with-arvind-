परीक्षा साथी — ऑनलाइन करने के लिए

यह प्रोजेक्ट Render Blueprint के लिए तैयार है। मैं इस चैट से आपके Render/GitHub खाते में लॉगिन करके वेबसाइट खुद प्रकाशित नहीं कर सकता, इसलिए लाइव URL अभी बना हुआ नहीं है।

सबसे आसान तरीका:
1. इस ZIP को डाउनलोड करके अपने GitHub में repository बनाकर इसकी सभी फाइलें upload करें। ZIP को सीधे Render में upload करने का विकल्प नहीं होता।
2. Render में New + → Blueprint चुनें और उस GitHub repository को connect करें। Render render.yaml पढ़कर service बनाएगा।
3. Environment variable ADMIN_PASSWORD के लिए अपना मजबूत पासवर्ड डालें; Apply/Deploy दबाएँ।
4. Deploy सफल होने पर Render जो onrender.com URL देगा, वही आपकी वेबसाइट होगी।

महत्वपूर्ण:
- एडमिन यूज़र आईडी: admin (यदि Render environment variable नहीं बदला)
- पासवर्ड: deploy करते समय ADMIN_PASSWORD में जो आप सेट करेंगे। कोई स्थायी डिफ़ॉल्ट लाइव पासवर्ड नहीं रखा गया है।
- Free hosting पर local SQLite data redeploy/restart के दौरान सुरक्षित रहने की गारंटी नहीं है। स्थायी परीक्षा/परिणाम डेटा के लिए persistent database/storage चाहिए।
